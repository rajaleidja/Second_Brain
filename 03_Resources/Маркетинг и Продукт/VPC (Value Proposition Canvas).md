### 1. Что это такое?

**Value Proposition Canvas (VPC / Шаблон ценностного предложения)** — это инструмент, созданный Александром Остервальдером, который помогает спроектировать продукт так, чтобы он **идеально соответствовал потребностям рынка** (состояние _Product-Market Fit_).

Если **JTBD** помогает понять, _зачем_ человек покупает продукт, то **VPC** берет эти знания и превращает их в конкретную _архитектуру фич и смыслов_.

### 2. Зачем он нужен?

1. **Избежать создания «ненужных» фич:** Перестать тратить недели на разработку функций, которые не решают ни одной реальной проблемы пользователя.
    
2. **Точная состыковка (Fit):** Убедиться, что на каждую ключевую боль клиента у твоего продукта есть прямое «обезболивающее».
    
3. **Основа для лендинга и офферов:** Готовая структура для написания продающего сайта, где каждый блок отвечает на конкретную эмоцию или потребность.
    

### 3. Анатомия VPC: Две стороны медали

VPC состоит из двух главных блоков: **Профиль клиента (Customer Profile)** и **Ценностное предложение (Value Map)**.

Plaintext

```
┌─────────────────────────────────┐        ┌─────────────────────────────────┐
│     ЦЕННОСТНОЕ ПРЕДЛОЖЕНИЕ      │        │        ПРОФИЛЬ КЛИЕНТА          │
│          (Ваш продукт)          │        │       (Рынок / Студент)         │
│                                 │        │                                 │
│  ┌───────────────────────────┐  │        │  ┌───────────────────────────┐  │
│  │    Продукты и Услуги      │  │        │  │   Задачи клиента (Jobs)   │  │
│  └───────────────────────────┘  │        │  └───────────────────────────┘  │
│                                 │  ◄───► │                                 │
│  ┌──────────────┐ ┌──────────┐  │ (MATCH)│  ┌──────────────┐ ┌──────────┐  │
│  │Обезболивающее│ │ Факторы  │  │        │  │ Боли и Страхи│ │ Выгоды и │  │
│  │   (Pain)     │ │ Gains    │  │        │  │    (Pains)   │ │Желания   │  │
│  └──────────────┘ └──────────┘  │        │  └──────────────┘ └──────────┘  │
└─────────────────────────────────┘        └─────────────────────────────────┘
```

#### Читаем Правый блок — Профиль клиента (Customer Profile):

1. **Customer Jobs (Задачи/Работы):** Что человек пытается сделать? (Контекст JTBD: _автоматизировать рутину, сдать проект, поднять чек_).
    
2. **Pains (Боли и Страхи):** Что его раздражает, пугает или мешает на этом пути? (_нет времени, сложно в коде, боюсь отдать деньги за плохой курс_).
    
3. **Gains (Выгоды и Желания):** Какой идеальный результат он мечтает получить? (_работать меньше, готовые скрипты, поддержка куратора_).
    

#### Читаем Левый блок — Ценностное предложение (Value Map):

1. **Products & Services (Продукты и Фичи):** Что конкретно ты даешь? (_Модули курса, шаблоны n8n, личный чат_).
    
2. **Pain Relievers (Обезболивающие):** Как твой продукт устраняет конкретные боли из правого блока?
    
3. **Gain Creators (Создатели выгоды):** Как твой продукт дает желаемые результаты из правого блока?
    

### 4. Практический пример: Состыковка для курса по n8n

Посмотрим, как боли студента превращаются в фичи курса и формулировки для сайта:

|**Профиль клиента (Изучаем студента)**|**Ценностное предложение (Строим курс)**|**Состыковка в маркетинг / Содержание**|
|---|---|---|
|**Pain (Боль):** «Боюсь застрять на ошибке в n8n/API и потерять часы на поиск проблемы».|**Pain Reliever:** Закрытый чат поддержки с разбором ошибок от автора/куратора за 15 минут.|**Фича:** «Технический SOS-чат: не останешься один на один с багом».|
|**Pain (Боль):** «Нет времени писать код с нуля, сложно учить JavaScript».|**Pain Reliever:** Библиотека готовых JSON-шаблонов для n8n (копируй и вставляй за 2 клика).|**Фича:** «Готовый конструктор: 15 готовых авто-сценариев в комплекте».|
|**Gain (Выгода):** «Хочу сразу внедрять ИИ в работу, а не просто читать теорию».|**Gain Creator:** Практические уроки по связке n8n + Gemini API для парсинга и генерации контента.|**Модуль:** «Сборка ИИ-агентов для Telegram за 1 вечер».|

### 5. Как провести проверку состыковки (Fit Check)

Когда ты заполнил обе стороны схемы, проведи идеальную линию от каждого пункта слева к пункту справа:

- 🟢 **Есть соответствие (Match):** Боли клиента закрыты твоими Pain Relievers $\rightarrow$ _Отличная фича, оставляем._
    
- 🔴 **Нет соответствия (Mismatch):**
    
    - У клиента есть боль, а у тебя **нет** фичи для ее устранения $\rightarrow$ _Уязвимость продукта._
        
    - У тебя есть классная фича, но она **не решает** ни одной боли и не дает выгоды $\rightarrow$ _Кандидат на удаление из курса (лишняя нагрузка)._
        

### 💡 Как использовать в Obsidian (Папка `1_Atlas`):

Внутри проекта создай файл `VPC_Ценностное_Предложение.md`. Заполни в нем две секции:

1. **Профиль аудитории** (Боли, Задачи, Выгоды).
    
2. **Матрица фич** (какой модуль или бонус закрывает какую боль).
    

Это защитит твой курс от «воды» и даст готовые заголовки для продающего сайта.
