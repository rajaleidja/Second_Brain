## 🎯 Цель урока и тайминг
- **Аудиторная часть (структуры данных, типы маппинга, выражения в n8n / JavaScript):** 40 минут.

- **Цель:** Научить участников уверенно преобразовывать данные между нодами, склеивать строки, вытаскивать вложенные параметры из JSON и использовать базовый JavaScript для сложных трансформаций.

## 🗣️ Сценарий речи преподавателя (Лекционная часть)

### Введение: Почему данные никогда не подходят друг другу
«Коллеги, в идеальном мире все программы говорили бы на одном языке. В реальном мире CRM присылает имя как `first_name`, бухгалтерская система ждет его как `Nimi`, а ИИ-модель требует вообще отдельным массивом в промпте. 

Если вы попытаетесь напрямую соединить выход одной ноды со входом другой, вы получите ошибку несоответствия типов. Здесь на помощь приходит **Маппинг (Mapping)** и нода трансформации **Set**. 
Вы должны научиться брать сырые данные (raw data) и превращать их в чистый, структурированный объект, понятный целевой системе».

### Выражения в n8n и базовый JavaScript
«В n8n встроен мощный движок выражений на базе JavaScript. Вам не нужно быть профессиональным программистом, но вы должны понимать базовые конструкции:
- Обращение к переменной: `{{ $json.body.email }}`
- Преобразование строки в верхний регистр: `{{ $json.name.toUpperCase() }}`
- Условия в одну строку (тернарный оператор): `{{ $json.age > 18 ? 'Adult' : 'Minor' }}`.
Мы разберем, как с помощью ноды `Code` обрабатывать сложные массивы данных за один проход, экономя десятки стандартных нод».

## 💻 Демонстрация / Практика

### Шаг 1: Использование ноды Set (Edit Fields)
Преподаватель показывает на экране:
- Как переименовывать ключи (`key -> new_key`).
- Как добавлять новые поля с вычисляемыми значениями (например, текущая дата через `{{ $now }}`).

### Шаг 2: Написание простого JS-кода в ноде Code
- Получаем на вход список сотрудников с разрозненными зарплатами.
- Пишем небольшой JS-скрипт для фильтрации сотрудников с зарплатой выше среднего и расчетом суммарного фонда оплаты труда.

## 📝 Домашнее задание и критерии сдачи
1. **Задание:** Собрать сценарий в n8n, который принимает массив данных о заказах с разным регистром букв в именах и неполными полями, производит нормализацию (приведение к единому регистру, удаление пробелов, расчет итоговой суммы с учетом налога) с помощью ноды Set или Code.
2. **Критерии сдачи:**
   - Все текстовые поля приведены к единому стандарту (например, имена с заглавной буквы).
   - Числовые поля имеют корректный числовой тип (не строка).
   - Сценарий отрабатывает без ошибок на массиве из минимум 5 элементов.
